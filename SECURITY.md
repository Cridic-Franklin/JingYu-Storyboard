# 安全政策 / Security Policy

## 简体中文

### 支持范围

安全修复以当前稳定版本 **V0.96** 为准。较早版本可能无法单独获得修复，请先确认问题能否在当前版本中复现。

### 私下报告安全问题

请优先使用 GitHub 的 **Private vulnerability reporting** 私下提交报告。如果该入口尚未启用，请通过仓库所有者的 GitHub 主页联系并索取私下报告方式。不要在公开 Issue 中披露漏洞细节、真实密钥、个人项目文件或其他敏感数据。

报告请包含受影响版本、复现步骤、实际影响和可行的最小复现。项目维护者会在条件允许时确认、评估并处理报告，但目前不承诺固定响应时限。

## English

### Supported version

Security fixes target the current stable release, **V0.96**. Older versions may not receive separate fixes; first confirm whether the issue reproduces in the current release.

### Reporting a vulnerability privately

Please use GitHub **Private vulnerability reporting** when available. If it is not enabled, contact the repository owner through their GitHub profile to request a private reporting channel. Do not disclose vulnerability details, real credentials, personal project files or other sensitive data in a public issue.

Include the affected version, reproduction steps, practical impact and the smallest useful reproduction. Maintainers will acknowledge, assess and address reports as capacity allows, but no fixed response time is currently promised.
