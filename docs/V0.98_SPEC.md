# SceneAxis V0.98 specification

## Product intent

SceneAxis is a lightweight spatial storyboard director. It positions proxy assets for blocking, spatial reasoning and composition; it is not a modeling, painting, animation or media-editing DCC. Spatial 3D, Plan 2D, Camera View, semantic export and AI enhancement all derive from one shot-owned Scene Graph.

## Release scope

- Official SceneAxis identity in header, navigation, favicon and application icon, with dark/light assets.
- Professional desktop shell with seven global navigation sections, grouped shot cards, compact icon controls, contextual menus, command palette, theme and text-size settings. Create contains preview-only Coming Soon entries for Script, Shot Planning and AI Storyboard.
- Shot metadata: sequence, type, duration, status, notes and structured references.
- PNG/JPEG storyboard reference import by picker or drag/drop, preview, fit/fill, replace/delete and local persistence.
- Expanded low-poly blocking library covering furniture, architecture, vehicles and common props.
- Character 2.0 proxy with readable body hierarchy, pose controls, semantic type and independent head facing.
- Object-owned motion paths with ordered editable points, visibility and real straight/smoothed rendering in Spatial 3D and Plan 2D.
- Spatial Description v3 with deterministic object/camera/motion facts, subject/screen/depth/orientation relations and a structured JSON inspection panel.
- Optional DeepSeek or OpenAI-compatible prose enhancement through a provider-neutral interface. Local deterministic generation remains the fallback and source of truth.
- Portable project schema 6 with safe legacy migration and pre-migration IndexedDB backup.

## Non-goals

No backend, cloud project store, account, collaboration, image generation, autonomous blocking solver, mesh modeling, rigging/IK, animation timeline or media editor is included. The structured shot-script and solver interfaces are extension points only.

## Acceptance contract

The production build must pass. The browser release pass covers reference import and persistence, shot/object workflows, view switching, motion paths, description generation, AI-disabled fallback, keyboard/command access, settings, project persistence and representative desktop widths. Public release notes are Chinese-first bilingual.
