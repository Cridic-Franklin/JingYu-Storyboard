# Storyboard Spatial Director

- Storyboard Spatial Director is a lightweight spatial storyboard tool.
- Assets are positioned, not modeled.
- 3D is for blocking and composition, not production rendering.
- Drawing features are for future annotation, not digital painting.
- Animation is outside the MVP.
- AI generation is outside the MVP.
- Do not introduce backend infrastructure unless explicitly requested.
- Prefer simple implementations over complex abstractions.
- Do not add features that were not requested.
- Maintain clean modular TypeScript architecture.

Run `pnpm build` and verify the browser workflow after meaningful changes. The application must work entirely in the browser; IndexedDB is the source of persisted project data.
